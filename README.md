# Proyecto 1 - Sistema de Gestión Fitness

Proyecto #1 de Técnicas de Programación (Universidad Politécnica Internacional).

Sistema en C# (Windows Forms) para que los usuarios de un gimnasio lleven el control de sus rutinas, visitas, mediciones, insignias y estadísticas, y para que los entrenadores administren las rutinas. Usa el patrón MVC y guarda los datos en archivos JSON/CSV.

## Estructura
- `src/Gimnasio` - Vistas (Windows Forms)
- `src/GimnasioController` - Controladores y manejo de archivos (IDataHandler, FileHandler)
- `src/GimnasioModels` - Modelos (Persona, UsuarioBasico, Entrenador, Rutina)
- `docs` - Documentación (Entregable #1 y documentación técnica)

## Cómo ejecutarlo
1. Instalar el SDK de .NET.
2. En la carpeta del proyecto ejecutar: `dotnet run --project src/Gimnasio`
